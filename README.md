# Program Konversi Suhu
Program sederhana berbasis bahasa Go untuk mengonversi nilai suhu dari Celsius ke Fahrenheit, Kelvin, dan Reamur melalui terminal.

## Fitur Program
Konversi suhu dari Celsius ke Fahrenheit
onversi suhu dari Celsius ke Kelvin
Konversi suhu dari Celsius ke Reamur (fitur tambahan)
Validasi pilihan menu dan batas suhu minimum (-273.15 Celsius)

## Teknologi yang Digunakan
Bahasa Pemrograman Go (Golang)
Git dan GitHub

## Cara Menjalankan Program
1. Pastikan Go sudah terinstal di komputer.
2. Buka terminal dan arahkan ke folder project ini.
3. Jalankan perintah berikut:
   go run main.go
